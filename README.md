# White Block

An [Aseprite](https://www.aseprite.org/) extension design to facilitate workflows for game development.

## Installation

Run `install.sh` from the project root. It symlinks the extension files into the Aseprite extensions folder.
Alternatively, copy `plugin.lua` and `package.json` directly into your Aseprite extensions folder.

## Usage

1. Open Aseprite.
2. Go to **File → Scripts → White Block**
